# 월간꽃밥

꽃밥이야기의 월간 소식지 사이트예요.
👉 **https://goodbabstory.github.io**

---

## 새 호 올리는 법

1. 이 저장소에서 **`_새호_양식.md`** 파일을 열고 내용을 모두 복사해요.
2. **`_posts`** 폴더로 들어가서 **Add file → Create new file**을 눌러요.
3. 파일 이름을 **`날짜-아무이름.md`** 형식으로 적어요.
   - 예: `2027-01-01-saehae.md` → 주소는 `goodbabstory.github.io/2027/01/`
   - 날짜는 꼭 **그 달**로 적어주세요. 한 달에 한 개씩이에요.
4. 복사한 양식을 붙여 넣고 제목과 내용을 바꾼 뒤 **Commit changes**를 눌러요.
5. 1~2분 뒤 사이트에 나타나요. 첫 화면의 "이번 호"도 자동으로 바뀌어요.

### 사진 넣기
1. **`assets/images`** 폴더에 그 달 폴더를 만들어요. (예: `assets/images/2027-01/`)
2. **Add file → Upload files**로 사진을 올려요. 파일 이름은 영어와 숫자로 해주세요. (예: `cover.jpg`, `photo1.jpg`)
3. 글 안에는 `![사진 설명](/assets/images/2027-01/photo1.jpg)` 처럼 적어요.
4. 위쪽 `cover:` 줄의 `#`을 지우고 경로를 적으면 대표 사진(카톡 미리보기 사진)이 돼요.

> 💡 휴대폰 사진은 용량이 커요. 올리기 전에 가로 1600px 정도로 줄이면 빨리 열려요.

### 글 꾸미기 (마크다운)
| 이렇게 쓰면 | 이렇게 보여요 |
|---|---|
| `## 제목` | 큰 소제목 |
| `### 제목` | 작은 소제목 |
| `**굵게**` | **굵게** |
| `> 인용문` | 분홍 상자 안의 문장 |
| `- 항목` | 점 목록 |
| `---` | ✿ ✿ ✿ 구분선 |

## 카카오톡으로 보내기
- 소식지 주소(예: `https://goodbabstory.github.io/2027/01/`)를 카카오채널 메시지에 붙여 넣으면 제목, 한 줄 소개, 대표 사진이 미리보기로 나와요.
- 미리보기가 예전 내용으로 나오면 [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 주소를 넣고 **캐시 초기화**를 눌러주세요.

## 좋아요·댓글 관리
- 데이터는 Firebase 프로젝트 **goodbabstory**의 Firestore에 저장돼요.
- 이상한 댓글 지우기: Firebase 콘솔 → Firestore Database → `issues` → 해당 달(예: `2027-01`) → `comments` → 댓글 선택 → 삭제
- 보안 규칙은 이 저장소의 `firestore.rules` 파일에 있어요. 바꾸면 Firebase 콘솔 → Firestore → 규칙 탭에 다시 붙여 넣고 게시해 주세요.

## 기본 설정
`_config.yml`에서 사이트 이름, 소개 문구, 카카오톡 채널 주소(`kakao_channel`)를 바꿀 수 있어요.
