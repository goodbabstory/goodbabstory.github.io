# 월간꽃밥

꽃, 밥에피다의 월간 소식지 사이트예요.
👉 **https://goodbabstory.github.io**

---

## 소식지 쓰기 (관리자 화면)

1. https://goodbabstory.github.io/admin/ 에 들어가요. 사이트 맨 아래 작은 **관리자** 글씨를 눌러도 돼요.
2. 관리자 아이디와 비밀번호로 로그인해요.
3. **＋ 새 호 만들기**를 누르고 몇 월호인지 적어요. (예: `2027-01`)
4. 호수, 제목, 한 줄 소개를 적어요.
5. 아래 화면은 **실제 사이트 모습 그대로** 편집돼요.
   - 글자를 눌러 바로 고치고, 사진 칸을 눌러 사진을 넣거나 바꿔요.
   - 글을 쓰는 중에는 위에 **서식 도구**(굵게, 크기, 색, 목록, 링크)가 떠요.
   - 블록을 누르면 **설정**에서 사진 모양(네모·둥근 모서리·타원·동그라미·아치), 사진 위치, 글자 크기·색, 배경색, 여백을 고를 수 있어요.
   - 블록 위 막대의 **⠿ 끌기**를 끌어서 순서를 바꾸고(↑ ↓ 버튼도 돼요), ⧉ 로 복제, 🗑 로 지워요.
   - 블록을 누르면 생기는 **✥ 손잡이**를 끌면 위치가, 오른쪽 **막대 손잡이**를 끌면 너비가 바뀌어요. 설정의 슬라이더나 방향키(←→↑↓, Shift를 누르면 크게)로 세밀하게 맞출 수 있어요.
   - 블록 사이 **＋** 를 누르면 새 블록을 넣을 수 있어요: 제목, 글, 사진, 사진+글, 제목|글, 인용, 사진 여러 장, 버튼, 구분선, 여백, **자유 배치**
   - **자유 배치** 블록은 판 안에 글상자·사진·선을 원하는 곳에 끌어다 놓는 블록이에요. ✥ 로 옮기고 모서리 □ 로 크기를 바꿔요. 판 아래 **↕ 판 높이**를 끌면 판이 길어져요. 휴대폰에서는 판 전체가 같은 비율로 작아져요.
   - 이미 만든 블록(제목, 글, 사진+글, 제목|글 등)도 설정 맨 위 **🔓 안의 글·사진 따로따로 움직이기**를 누르면 지금 모습 그대로 자유 배치로 바뀌어요.
6. **사이트에 공개**에 체크하고 **저장**을 눌러요. 체크하지 않으면 관리자만 볼 수 있어요.

> 💡 첫 번째 사진이 첫 화면 카드의 대표 사진이 돼요. 휴대폰에서는 "사진+글", "제목|글" 블록이 자동으로 위아래로 바뀌어요.

## 댓글 관리
- 독자는 **이름과 비밀번호**를 적고 댓글을 남겨요. 같은 비밀번호로 언제든 수정하거나 지울 수 있어요.
- 관리자로 로그인한 상태에서 소식지를 열면 모든 댓글 옆에 **삭제(관리자)** 버튼이 보여요. 비밀번호 없이 바로 지울 수 있어요.

## 카카오톡으로 보내기
- 소식지 주소(예: `https://goodbabstory.github.io/read/?m=2027-01`)를 카카오채널 메시지에 붙여 넣으면 돼요.
- 링크 미리보기는 모든 호가 같은 "월간꽃밥" 대표 이미지로 나와요. 호마다 다르게 보여주고 싶으면 카카오채널 메시지를 쓸 때 사진과 제목을 직접 넣어 주세요.

## 데이터와 보안
- 글, 사진, 좋아요, 댓글은 Firebase 프로젝트 **goodbabstory**의 Firestore에 저장돼요.
- 관리자 계정은 Firebase 콘솔 → Authentication → 사용자 에서 관리해요. (아이디 `yeriberry` = `yeriberry@goodbabstory.admin`)
- 보안 규칙은 이 저장소의 `firestore.rules` 파일에 있어요. 바꾸면 Firebase 콘솔 → Firestore → 규칙 탭에 다시 붙여 넣고 게시해 주세요.

## 개발 참고
- `_config.yml`: 사이트 이름, 소개 문구, 카카오톡 채널 주소(`kakao_channel`), Firebase 설정
- `assets/js/`: 블록 모양(`blocks.js`), 첫 화면(`home.js`), 소식지 화면(`read.js`), 관리자 화면(`admin.js`)
- `assets/vendor/`: Firebase, DOMPurify 라이브러리 묶음. `_vendor-src`에서 `npm install && npm run build`로 다시 만들 수 있어요.
